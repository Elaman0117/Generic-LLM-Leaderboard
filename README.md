### 评分方法

1. **15项Intelligence子指标**各自线性归一化到 [0,1]（最低→0，最高→1，"--"忽略）
2. **综合能力值** = 所有有效归一化分数的算术平均
3. **Pareto前沿** = 不被任何其他模型支配的模型（不存在单次更便宜且更强的选择）

### 指数化映射方法

**X轴（价格）**：
1. 单次请求价格经 min-max 归一化到 [0,1]（normalized_cost）
2. 按排名均匀映射：exponential_cost = rank / (n-1)，使价格从0到1均匀分布

**Y轴（综合能力）**：
1. 综合能力再归一化：ability_rescaled = (ability - min) / (max - min)，使最低=0，最高=1
2. 按排名均匀映射：exponential_ability = rank / (n-1)，使综合性能也从0到1均匀分布

### 精确分数计算

本版本使用 Python `fractions.Fraction` 进行**全程精确有理数运算**：
- 所有解析值（价格、速度、延迟、指标分数）均以 `Fraction` 存储
- 归一化、均值、比值、价格计算均使用精确分数运算，**无浮点舍入**
- 指数化排名映射也使用 Fraction 精确计算
- 仅在**绘图坐标传入 matplotlib** 及 **JSON 序列化输出**时才转为浮点数

### 单次请求价格计算

```
输入输出比 r = (Blended - Output_Price) / (Input_Price - Output_Price)

# 非推理模型 & 推理模型（有 Reasoning Time）：
输出tokens = (Total_Response - TTFT) × Speed
# 对推理模型：TTFT=首CoT token时间，(Total-TTFT)已含reasoning+可见输出，不加倍

# 推理模型（无 Reasoning Time）：
输出tokens = Total_Response × Speed
# CoT不可见→first chunk无意义，假设全程都在生成token

输入tokens = 输出tokens × r / (1-r)
单次价格 = (输入tokens × Input_Price + 输出tokens × Output_Price) / 1,000,000

# 以上所有运算均使用 Fraction 精确计算
```
