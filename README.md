### 评分方法

1. **15项Intelligence子指标**各自线性归一化到 [0,1]
2. **综合能力值** = 所有有效归一化分数的算术平均
3. **Pareto前沿** = 不被任何其他模型支配的模型

### 指数化映射方法

**映射函数**：f(x) = x^p，其中 p = log(0.5) / log(median_pareto)

**核心原则**：
- 映射是连续数学函数，不是排名重分配
- f(0) = 0, f(1) = 1（端点不变）
- f(median) = 0.5（中位数映射到0.5，使分布以0.5为中心）
- 参数 p 仅由帕累托前沿模型的数据分布决定

**X轴（价格）**：
1. 所有模型单次请求价格 min-max 归一化到 [0,1]
2. 仅取帕累托前沿模型的归一化价格中位数，计算 p_x
3. 对所有模型应用 exponential_cost = normalized_cost^p_x

**Y轴（综合能力）**：
1. 综合能力再归一化：最低=0，最高=1
2. 仅取帕累托前沿模型的再归一化中位数，计算 p_y
3. 对所有模型应用 exponential_ability = ability_rescaled^p_y

### 精确分数计算

全程使用 Python `fractions.Fraction` 进行精确有理数运算：
- 所有解析值、归一化、均值、比值、价格计算均使用精确分数
- 幂函数映射 f(x) = x^p 参数由 Fraction 中位数确定，映射本身因非整数指数需用 float
- 仅在绘图坐标传入 matplotlib 及 JSON 序列化时转为浮点数

### 单次请求价格计算

```
输入输出比 r = (Blended - Output_Price) / (Input_Price - Output_Price)
非推理/推理有ReasonT: 输出tokens = (Total_Response - TTFT) × Speed
推理无ReasonT: 输出tokens = Total_Response × Speed
输入tokens = 输出tokens × r / (1-r)
单次价格 = (输入tokens × Input_Price + 输出tokens × Output_Price) / 1,000,000
```
